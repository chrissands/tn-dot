# Tabs Block

Tabbed content box styled after the tn.gov tab component (e.g. Yellow DOT Program).

<!-- excat-authoring-guide:start -->
## Migration authoring guide

### Authoring (Document Authoring)

One row per tab: **label** | **content** (rich text, images, lists).

- From 600px wide: tabs (arrow keys move between tabs). Below 600px: collapsed accordion headers that open independently.
- **Video:** a paragraph with only an image, followed by a paragraph with only a YouTube or Vimeo link, becomes a video: the image is the poster, the link text (e.g. "Watch video") is the play label.
- **Links panel:** an H3 directly followed by a list whose items are single links renders as a panel with a gray title bar (e.g. "Related Links").
- Images on their own line are centered at natural size.
